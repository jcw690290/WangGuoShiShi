# 地图来源与许可

原图作品名为 *MapChart Map*，由 MapChart.net 提供。仓库保留了用户提供的 1820 年着色 SVG 及其内嵌署名和许可元数据。[Victoria 3 州地图](https://www.mapchart.net/victoria-3.html) · [MapChart 地图使用条款](https://www.mapchart.net/terms.html)

本项目将地图转换为使用原图平面坐标的 GeoJSON，关联州 ID 和剧本归属，推算州邻接与沿海标记，并按游戏中的当前归属重新着色。原图和这些地图改编部分均按 [Creative Commons 署名—相同方式共享 4.0 国际许可](https://creativecommons.org/licenses/by-sa/4.0/) 提供。
