## 王国史诗 · 1820 世界剧本

本地浏览器单机 Demo。可从 26 个国家中选国，在包含 660 个州和 3 个 AI 背景势力的地图上推进经济、人口、政治、科技、外交和战争。

使用 Node.js 22.18 或更高版本，在仓库根目录运行：

```sh
npm ci
npm run dev
```

打开 [本地游戏](http://localhost:5173)。

地图支持单指拖动、双指捏合缩放和轻触选州；桌面可用滚轮、方向键、`+` / `-` 和 `Home`。保留“定位选中州”和“全图”，不再使用放大/缩小按钮。选国后搜索或点选无主州，支付 **500 两**即可占领，立即获得人口、市场和建设权限（Demo 平衡值，不限制接壤或跨海）。占领结果可正常存读档。

验证使用 `npm test` 和 `npm run build`，构建包含类型检查。[机制与试玩记录](MECHANICS.md) · [地图署名与许可](resources/MAP-LICENSE.md)

## 好友联机

在「联机」中创建房间并分享房间码或邀请链接。至少两位成员分别选国后，由房主开始。开局暂停，房主可选择每 1、2 或 4 秒推进一个游戏日，随时暂停或继续。推进期间所有玩家都能对自己的国家下指令，非玩家国家继续由 AI 管理。

房主浏览器负责模拟。Supabase 持久化指令、日步进结果和世界快照，通过私有 Realtime 房间通知成员并显示在线状态。房主退出、切到后台或长时间断线时对局暂停；使用原浏览器身份返回房间后，房主可以继续推进。同一个房间在另一标签页打开时，仅持有控制权的标签页能推进日期。游客身份保存在浏览器，换设备或清空浏览器数据后无法以原身份续玩。首版适合互相信任的朋友，房主掌握结算结果。

### 本地和 Vercel 配置

1. 在 Supabase 项目启用 [匿名登录](https://supabase.com/docs/guides/auth/auth-anonymous) 和 Realtime，应用 `supabase/migrations` 里的联机迁移。
2. 本地将 [环境变量模板](.env.example) 复制为 `.env.local`，填写项目 URL 和 publishable key；Vercel 的 Preview 和 Production 构建使用同名变量。
3. 本地运行 `npm run dev`，或重新部署 Vercel。两位玩家分别用两个浏览器配置文件打开同一版本进行试玩。未配置联机变量时仍可玩单机。

### 双人验收

1. 房主创建房间，第二位玩家使用邀请链接加入。选择不同国家，开局后双方显示相同日期且处于暂停状态。
2. 由第二位玩家提交建设或研究，等待「指令已执行」，确认双方读到相同的世界变化。房主继续推进超过一周，再暂停并核对日期和结算结果。
3. 刷新第二位玩家的页面，在联机菜单选择「继续上次房间」，核对国家及日期。关闭房主页面，确认日期停止；使用原浏览器返回房间后确认对局从云端存档继续。
