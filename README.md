# WangGuoShiShi
Ni Hao Wang Hong Yu
Ke Bi Lai Xi

## 王国史诗 · 1820 世界剧本

本地浏览器单机 Demo。可从 29 个国家中选国，在 660 个州的地图上推进经济、人口、政治、科技、外交和战争。

使用 Node.js 22.18 或更高版本，在仓库根目录运行：

```sh
npm ci
npm run dev
```

打开 [本地游戏](http://localhost:5173)。验证使用 `npm test` 和 `npm run build`，构建包含类型检查。[机制与试玩记录](MECHANICS.md) · [地图署名与许可](resources/MAP-LICENSE.md)
